# Changelog

## 1.0.0 (2026-10-05)

First release.

- Custom functions: `APIDIRECT_SEARCH`, `APIDIRECT`, `APIDIRECT_AI`, `APIDIRECT_ENDPOINTS`, `APIDIRECT_FIELDS`.
- Sidebar: pick a platform and endpoint, fill in parameters, write the results into any range.
- Scheduled refreshes: append only new results (saved searches) or replace a table every hour, 6 hours, 12 hours, day or week.
- 100 endpoints across Twitter/X, Facebook, Instagram, TikTok, YouTube, Reddit, Threads, Truth Social, Bluesky, LinkedIn, Amazon, Trustpilot and Google (web search, AI Mode, news, forums, Places).
- API key stored per user in PropertiesService; responses cached for six hours so reopening a sheet does not bill again.
